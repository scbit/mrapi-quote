# MRAPI Quotes MVP v20

## Productos — Shenzhen Sentire Trading

### Foto
- Adjuntar JPG / PNG / WEBP directamente desde la ficha del producto.
- Vista previa antes de guardar.
- La imagen se guarda en Cloud Storage y se sirve desde MRAPI Quotes.
- Se puede reemplazar editando el producto.

### Categorías
- Campo de categoría con buscador/desplegable.
- Mantiene las categorías ya usadas en productos existentes.
- Si se escribe una categoría nueva, se crea automáticamente.
- Panel de Categorías con buscador, alta, edición y borrado.

### Proveedores
- Panel de Proveedores.
- Nombre real privado para uso interno.
- Alias externo para documentos del cliente (Proveedor 1, Proveedor 2, etc.).
- Contacto, ciudad, moneda, lead time y notas internas.
- Un producto puede vincular varios proveedores.

### Fabricantes
- Panel separado de Fabricantes.
- Fabricante puede ser distinto del proveedor.
- Un producto puede seleccionar su fabricante.

### Producto
- Ahora muestra proveedor/es y fabricante en la tabla.
- Botón Editar y Borrar.
- El perfil logístico sigue estando solamente en la cotización, no en el producto.

### PDF
- Más espacio vertical en Datos Generales.
- Operación y Modalidad quedan separados del texto superior para evitar que queden pegados a los marcos.

- PDF de cotización reajustado para verse más profesional y más limpio.
- Mejorado el bloque superior derecho `Detalle de cotización` para evitar cortes y desalineaciones.
- Rehecho el bloque final de productos como:
  `Costo final por producto puesto en Argentina`.
- El bloque ahora explica la lógica al cliente:
  `FOB + logística proporcional por m³ + impuestos al costo - deducciones de impuestos recuperables`.
- Nueva tabla por producto con columnas:
  - Producto
  - FOB
  - CBM
  - Logística
  - Impuestos
  - Deducciones imp.

- Si la cantidad es mayor a 1, se muestra también el costo unitario final.

Dejar el PDF más profesional para enviar al cliente y hacer más entendible el costo real / final puesto en Argentina.
